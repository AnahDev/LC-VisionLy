## ⚙️ Instalación de Dependencias

El único código que requiere una librería externa es el parser LR de la **Pregunta 2**, que utiliza `ply`.

Navega a la carpeta raíz del proyecto y ejecuta:

```bash
pip install -r src/pregunta2/requirements.txt
```
